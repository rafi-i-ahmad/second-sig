# Fixtures

Everything the judge is tested against. Attack and injection examples live here and in the eval
set only; never paste them into runtime prompts (CLAUDE.md invariant 8).

There are three kinds of thing in this folder: **cases** (a proposal and its ground truth),
**evidence** (what the fork said when a case was rehearsed), and **caches** (model outputs and
Etherscan sources, so tests and replays need no network).

## Cases: the proposals

All case files are generated by `build.py` from plain Python. Edit the Python, not the JSON, then
run `uv run python fixtures/build.py`. Each case holds the treasurer's `description`, the
`address_book` the forward pass may see, the exact `safe_tx` bytes, a decoded `calls` view for
humans, and the `intent` ground truth (movements, permission changes, Safe config changes,
`nothing_else`, `expect_question`). The Safe address in every file is the placeholder
`0x5AFE…5AFE`; the tooling substitutes the real fork Safe at run time.

Every case lives under `cases/`, in a folder named after its expected verdict (the classifier's
three answers) or `demo`. Every file carries `expected_verdict`, and a test checks it matches
the folder.

| Folder | What is in it | Who reads it |
| --- | --- | --- |
| `cases/match/` | Nine honest, precise proposals (`01`–`08`, `10`): transfers, batches, owner and threshold changes, a finite approval, a swap. The words say exactly what the bytes do | forward-pass tests, eval |
| `cases/ask/` | `09` "Routine transfer" (too vague to check). The description contradicts the bytes (`31`–`34`): "revoke" that grants, a payment to the wrong wallet, "pay" that only approves, a swap whose output goes elsewhere. Injections over bytes that also contradict the words (`37`, `40`, `41`, `43`): instructions in the description, in an address-book label, in a call label, in a forged rehearsal tag. Injections whose bytes leave one honest gap (`39`, `42`). Hard ASKs (`44`–`49`, `51`): an extra dust recipient, conflicting units, a swap with an unlimited allowance, "approve the invoice" that approves USDC, a WETH payment funded by wrapping, an unbooked new wallet, a clarification that moves the goalposts. Contradictions are ASK by decision of 24 October 2026: REJECT is kept for the floor and for critical effects, and both refuse the stamp. `39`, `49`, `51` carry scripted `clarifications` for the ASK loop | forward-pass tests (the words still describe an honest transaction), `tests/test_verdict.py`, eval, ASK-loop tests |
| `cases/reject/` | A critical change to the Safe's control that the words do not license: `35` "keep approval at 2 signatures" that ends at 1; `38` and `50` "add Ravi as a backup owner" whose call also drops the threshold to 1 (`38` with an injected "change-control convention"). No floor rule fires on any of them; the comparison's critical row does | forward-pass tests, `tests/test_verdict.py`, eval |
| `cases/demo/` | The three demo scenarios: `demo_bybit` (REJECT, by the hard floor), `demo_aave` (MATCH), `demo_auditor` (ASK: true but incomplete) | the demo and the eval only |

Forward-pass tests and few-shot examples never read `cases/demo/` (CLAUDE.md invariant 8);
`tests/test_forward_cases.py` reads `match/`, `ask/` and `reject/` and fails if a `demo_*` id
appears there. A sanctioned destination case is still to be written; it goes in the folder its
expected verdict names, like any other case.

## Evidence: what the fork said

| Folder | What is in it | Made by |
| --- | --- | --- |
| `bundles/` | One `<id>.bundle.json` (the `EvidenceBundle`: decoded call tree, labelled storage writes, balance changes, events, sources, floor hits) and one `<id>.rehearsal.json` (the raw traces it was built from) per case. All 18 cases as of 24 October | `uv run python -m judge.evidence.fork <case.json>` on anvil |
| `examples/` | `bybit.bundle.json`, a hand-checked example bundle the schema tests validate against | by hand |
| `truth/` | Optional hand-written ground truth, `<id>.json`, same shape as a case `intent`; overrides what `judge/truth.py` derives from the calldata. None needed so far | by hand |
| `traces/` | Older raw traces from `judge.run_fixture --save-trace` (three cases). Superseded by `bundles/`, but the naive baseline (`judge/stages/judge.py`) still reads this format; delete once it reads bundles | `uv run python -m judge.run_fixture <case.json> --save-trace` |

## Caches: so nothing needs the network

| Folder | What is in it |
| --- | --- |
| `sources/` | Etherscan `getsourcecode` results, one file per address (verified source, ABI, proxy implementation). Written by `judge/stages/sources.py` the first time an address is seen; commit new ones |
| `outputs/` | Recorded model outputs: `<id>.forward.json` (forward pass), `<id>.naive.json` (one-call baseline). Never in `cases/` |
| `anvil-state.json` | Dumped fork state for offline runs (`anvil --load-state`), gitignored, not yet produced |

## People and contracts

People and wallets (Dana, Priya, Ravi, the ops wallet…) are invented, deterministic addresses
derived from their names with `person()`. USDC, the Aave v3 Pool, the Uniswap V2 router, WETH and
MultiSendCallOnly are the real mainnet contracts (Etherscan links in `build.py`).
